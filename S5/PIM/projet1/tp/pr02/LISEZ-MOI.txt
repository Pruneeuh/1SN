# Exercice 1

## Question 1.4

**Indiquer les inconvénients/avantages d'une implantation par listes chaînées
d'une SDA.**

Avantages : pas de limite sur le nombre de couples Clé-Valeur; alloue uniquement la mémoire nécessaire et pas plus
Inconvenients : recherche d'une clé plus long puisqu'on est obligé de parcouir toute la lsite élement par élément; nécessité de stocker/gérer l'adresse vers l'élement suivant; rique de fuite de mémoire

## Performance comparée de LCA et TH

Indiquer ici les résultats obtenus.

Pour Borne = 1000, Taille = 100000

    Borne  : 1000
    Taille : 100000

    Max : 140

    real	0m0,011s
    user	0m0,010s
    sys	0m0,000s

Pour un LCA : 
    Borne  : 1000
    Taille : 100000
    Min : 69
    Max : 133

    real	0m0,504s
    user	0m0,503s

Le type TH est donc plus efficace (ce qui est cohérent vu qu'il n'a pas besoin de parcourir toutes les clé pour récupérer une valeur.
